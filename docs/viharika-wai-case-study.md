# Viharika Wai — Villa Advertisement

> **Project type:** Hospitality creative portfolio project  
> **Format:** Vertical short-form video (YouTube Short)  
> **Featured video:** [Watch the Viharika villa advertisement](https://youtube.com/shorts/L04p-pjvdz4)

## Project overview

This project explores how a short, visually led video can introduce a villa stay and help potential guests imagine the experience. The creative direction focuses on presenting the property as a destination rather than simply listing amenities.

## Creative objectives

- Make the property feel appealing within the first few seconds.
- Use a vertical format suited to mobile-first discovery.
- Build a clear visual mood for a hospitality audience.
- Create a finished video that can be reviewed as part of a property-marketing portfolio.

## Deliverable

- One vertical villa-promotion video published as a YouTube Short.
- A portfolio entry linking directly to the published creative.

## How this could be tested in a real campaign

These are **proposed tests, not reported campaign results**:

1. **Experience-led hook:** Open with the most emotionally compelling property visual.
2. **Feature-led hook:** Lead with a standout feature, using only verified property details.
3. **Audience test:** Compare relevant traveller segments only when there is enough budget and a clear testing plan.
4. **Creative test:** Change one major variable at a time so the result is easier to interpret.
5. **Measurement:** Track outbound clicks, landing-page views, enquiries and confirmed bookings where tracking and permissions are properly configured.

## Metrics to evaluate

| Metric | What it helps answer |
|---|---|
| 3-second video plays / hook rate | Does the opening hold attention? |
| Average watch time / completion rate | Do viewers keep watching? |
| CTR (link click-through rate) | Does the creative motivate action? |
| CPC (cost per link click) | How much does each click cost? |
| Cost per enquiry or booking | Is the campaign generating useful outcomes? |
| ROAS | For trackable booking revenue, how does attributed revenue compare with ad spend? |

**Important:** No ad-spend, conversion, booking or ROAS results are claimed here. Add verified numbers only after a real campaign has run.
